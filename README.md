# airline.ez ✈️

เกมสายการบินแบบง่าย เล่นบนเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้ง

- เริ่มที่กรุงเทพฯ เปิดเส้นทางไปเมืองต่างๆ แล้วซื้อเครื่องบินใส่
- เงินเข้าทุกสิ้นวัน = ค่าตั๋ว − น้ำมัน − ค่าดูแลเครื่อง
- เส้นทางไหนที่นั่งไม่พอ ให้เพิ่มเครื่อง
- กำไรสะสมถึงเป้าจะขึ้นเลเวล และเปิดภูมิภาคใหม่ (อาเซียน → เอเชียตะวันออก → ตะวันออกกลาง → โอเชียเนีย → ยุโรป → อเมริกา)

## ไฟล์
- `index.html` หน้าเว็บ
- `css/style.css` หน้าตา
- `js/data.js` เมือง 75 แห่ง
- `js/geo.js` แผนที่โลก (Natural Earth, public domain)
- `js/game.js` ตัวเกม
- `sw.js`, `manifest.webmanifest` ติดตั้งเป็นแอปและเล่นออฟไลน์ได้

## เปิดเล่น
เปิด `index.html` ในเบราว์เซอร์ หรือเปิด GitHub Pages ของ repo นี้
